# Guild Legacy — Story RPG

Prototipo narrativo de fantasía medieval donde el jugador dirige una party de cuatro aventureros y ChatGPT actúa como contador de historias y director visual.

## Loop actual

1. La página muestra la escena vigente, su imagen pixel-art y el estado de la party.
2. El jugador selecciona una de cuatro decisiones.
3. La elección se continúa en el chat.
4. ChatGPT genera consecuencias narrativas + una nueva imagen coherente + cuatro nuevas opciones y actualiza este repositorio.

## Party de prueba

- Garran Voss — Guerrero / protector
- Lyra Veyne — Hechicera / daño mágico
- Nilo “Rata” Serrat — Pícaro / exploración y daño físico
- Hermano Aldren — Sacerdote / curación y apoyo
