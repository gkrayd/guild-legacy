# Guild Legacy

Prototype web game focused on guild management, autonomous expeditions, character growth, relationships and generational progression.

## Current version
V0.3 — Mobile Landscape UI.

## Core loop
Recruit adventurers -> form a party -> choose a mission -> autonomous expedition -> review consequences -> improve the guild.

## Current systems
- Recruitment
- Six fantasy classes
- Traits and personality
- Party formation
- Autonomous expeditions
- XP and leveling
- Injuries and death risk
- Bonds, tension and attraction
- Guild chronicle
- Character detail screen
- Mobile landscape navigation
- Local browser save

## UI direction
The project is designed mobile-first for a phone held horizontally. The V0.3 interface separates the game into Guild, Adventurers, Party, Mission and Chronicle screens.
